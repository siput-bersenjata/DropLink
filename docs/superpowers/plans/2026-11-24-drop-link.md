# Drop Link Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun aplikasi web berbagi file sementara (Drop Link) tanpa login, dengan batas ukuran 20MB untuk gambar dan 50MB untuk video/dokumen, masa simpan 1–6 bulan, penyimpanan Cloudflare R2 (10GB gratis), proteksi Cloudflare Turnstile, perekaman audit log perangkat & IP, dan deploy ke Vercel dengan repositori GitHub.

**Architecture:** Frontend Next.js (App Router) dengan Tailwind CSS mereplikasi desain visual DropLink (Hero, Blue Dashed Dropzone, 3 Kolom Nilai Tambah, Navbar, Footer, dan Halaman Pratinjau/Unduh). Serverless API Next.js menangani verifikasi Turnstile, rate limiting IP, audit logging perangkat ke database serverless, dan menghasilkan S3-Presigned URL agar browser mengunggah file langsung ke Cloudflare R2 tanpa membebani bandwidth Vercel. Dual-layer cleanup (on-access check + daily Vercel cron) menghapus file yang melewati masa aktif (1, 3, 6 bulan).

**Tech Stack:** Next.js 14+ (App Router, TypeScript), Tailwind CSS, Lucide React, Cloudflare Turnstile (@marsidev/react-turnstile), @aws-sdk/client-s3, @aws-sdk/s3-request-presigner, Drizzle ORM / LibSQL (SQLite/Postgres), ua-parser-js, Vitest untuk automated testing.

**Spec:** `docs/superpowers/specs/2026-11-24-drop-link-design.md`

## Global Constraints
- Akses anonim: Tidak ada sistem registrasi/login pengguna.
- Batas ukuran file: Gambar maksimal 20 MB; Video maksimal 50 MB; Dokumen & arsip maksimal 50 MB; Batas absolut semua file 50 MB.
- Ekstensi terlarang (blacklist): `.exe`, `.bat`, `.cmd`, `.sh`, `.php`, `.js`, `.vbs`, `.msi` ditolak secara mutlak.
- Pilihan masa aktif (retention): Hanya menerima nilai `1`, `3`, atau `6` (dalam satuan bulan).
- Penyimpanan: Cloudflare R2 (S3-compatible API, 10 GB kuota gratis, 0 biaya egress).
- Keamanan: Wajib verifikasi token Cloudflare Turnstile sebelum presigned URL dikeluarkan.
- Audit Log: Wajib mencatat IP, Browser, OS, Tipe Perangkat, dan Resolusi Layar pada setiap upload.
- Pengunggah: Diberikan *Delete Key* rahasia untuk menghapus file secara instan sebelum kedaluwarsa.
- Tampilan: Mengikuti presisi tata letak desain visual DropLink yang disediakan pengguna.

## Review Focus
1. Upaya upload file melebihi batas (misal gambar 25MB atau video 60MB): Harus ditolak di client dan server dengan pesan error ramah sebelum presigned URL dibuat.
2. File dengan ekstensi berbahaya atau tipe MIME terselubung: Harus diblokir total dengan error 400.
3. Permintaan presign tanpa atau dengan token Turnstile yang tidak valid: Harus ditolak dengan status 403 Forbidden.
4. Akses ke file yang sudah melewati masa kadaluarsa (`now() > expires_at`): Mengembalikan halaman status 410 Gone / Expired dan memicu penghapusan objek di Cloudflare R2.
5. Penghapusan file menggunakan Delete Key yang salah: Menolak dengan status 403, dan hanya menghapus jika token hash cocok dengan database.

describe('File Validator', () => {
  it('should accept image under 20MB', () => {
    const result = validateFile({ filename: 'photo.png', size: 15 * 1024 * 1024, mimeType: 'image/png' });
    expect(result.valid).toBe(true);
    expect(result.category).toBe('image');
  });

    expect(result.valid).toBe(false);
    expect(result.error).toContain('20MB');
  });

  it('should accept video under 50MB', () => {
    const result = validateFile({ filename: 'clip.mp4', size: 45 * 1024 * 1024, mimeType: 'video/mp4' });
    expect(result.valid).toBe(true);
    expect(result.category).toBe('video');
  });

  it('should reject video over 50MB', () => {
    const result = validateFile({ filename: 'movie.mp4', size: 55 * 1024 * 1024, mimeType: 'video/mp4' });
    expect(result.valid).toBe(false);
    expect(result.error).toContain('50MB');
  });

  it('should reject dangerous executable files', () => {
    const result = validateFile({ filename: 'virus.exe', size: 1024 });
    expect(result.valid).toBe(false);
    expect(result.error).toContain('tidak didukung');
  });

  it('should calculate expiry date accurately for 1, 3, 6 months', () => {
    const now = new Date();
    const expiry1 = calculateExpiryDate(1);
    const diffDays = Math.round((expiry1.getTime() - now.getTime()) / (1000 * 60 * 60 * 24));
    expect(diffDays).toBeGreaterThanOrEqual(28);
    expect(diffDays).toBeLessThanOrEqual(31);
  });
